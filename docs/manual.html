AllinOneDesign 사용 설명서

요구사항에서 시스템 다이어그램 → 회로 → PCB → 기구까지, 브라우저 하나에서 AI와 함께 설계하는 도구입니다. 이 설명서는 화면 순서대로 따라가며 읽도록 썼습니다.

소개

AllinOneDesign은 단일 HTML 파일로 동작하는 하드웨어 설계 작업 공간입니다. 한 프로젝트의 산출물(HW 블록 다이어그램, 회로도·넷리스트·BOM, 배치·배선된 PCB, 보호 하우징 도면·BOM, HSIS, 시뮬레이션, 리비전 이력)이 한 곳에 있고, 어느 단계에서든 설계 도우미(AI)에게 말이나 명령으로 지시할 수 있습니다.

신규 설계요구사항 한 줄에서 시작해 4단계를 차례로 진행합니다. 빠진 정보는 AI가 질문합니다.
기존 프로젝트KiCad · Gerber · 뷰어 JSON을 열어 보고, 편집하고, 시뮬레이션·HSIS·기구까지 이어 갑니다.
AI 설계 도우미네 단계의 콘솔을 하나의 대화로. 변경은 "변경 요청 카드"로 검토·승인·되돌리기.
리비전·내보내기바뀔 때마다 자동 기록, 두 시점 비교, SVG/PNG/Excel/설계 보고서(HTML→PDF).
열·진동·EMC·단가·하우징 수치는 초기 설계용 추정입니다. 양산 전에는 전문 도구와 시험으로 확인하세요.

시작하기

  1. dist/index.html을 브라우저(Chrome·Edge 권장)로 엽니다. 3D·zip·엑셀 라이브러리만 CDN에서 불러오므로 인터넷이 필요합니다. 설계 파일은 브라우저 안에서만 처리됩니다.
  2. 첫 화면에서 신규 설계 또는 기존 프로젝트를 고릅니다. 아래의 예제 칩(SENSE-32, MCU DC 모터, MCU BLDC 3상, AURIX TC364)을 누르면 바로 둘러볼 수 있습니다.
  3. 머리의 로고 아이콘을 누르면 언제든 첫 화면으로 돌아옵니다.

신규 설계 4단계

첫 화면의 신규 설계를 누르면 빈 프로젝트가 열리고 1단계부터 시작합니다. 단계는 순서대로 열립니다(회로 없이는 3단계로 못 가고, PCB 배치 전에는 4단계가 잠깁니다).

1단계 · 시스템 다이어그램

  1. 왼쪽 패널에 프로젝트 이름과 요구사항(무엇을 만들지 · 입력 전원 · 통신 · 구동/센싱 · 안전 등급)을 적습니다. 예제 칩을 누르면 문장이 채워집니다.
  2. 블록 다이어그램 만들기를 누르거나, 오른쪽 도우미에 문장을 바로 보냅니다.
  3. 빠진 필수 정보가 있으면 도우미에 질문 카드가 뜹니다. 선택지를 누르거나 직접 적어 답하세요(건너뛰면 기본값). 답은 요구사항에 보강: …으로 합쳐집니다.
  4. HW 블록 다이어그램이 그려집니다. 블록을 누르면 왼쪽 아래에서 기능·인터페이스·회로 구현을 고칠 수 있고, 명령(block · link · feat · rename · del)으로도 편집합니다.
  5. 다음: 회로 생성 →으로 2단계로 갑니다.
AI 모드(도우미 머리의 AI)에서는 Claude가 질문을 고르고 블록을 설계합니다. 결정론 모드에서는 규칙으로 같은 일을 합니다. 1단계에서는 PCB 조건을 묻지 않으며, 도킹 패널도 설계 도우미만 보입니다.

2단계 · 회로

  1. 다이어그램이 저가형 · 표준 · 확장형 세 회로 안으로 풀립니다. BOM 참고가, 부품 수, 여유 MCU 핀, 레귤레이터 손실, 가격·기능·확장성 점수와 기준 안과의 차이를 비교합니다. 위의 우선순위(가격 · 균형 · 기능 · 확장성)로 추천이 바뀝니다.
  2. 이 안으로 회로 생성을 누르면 실제 부품 선정 · 넷리스트 · MCU 핀 배정 · 회로도(여러 시트)가 만들어집니다. 이 단계에서는 회로도만 보이고 PCB 관련 화면은 숨겨집니다.
  3. 데이터시트 탭에서 회로 부품 목록(참고 단가 합)과 부품별 정리 페이지를 봅니다. 회로도는 회로 편집으로 직접 고치거나 회로도 CLI(add · move · wire · erc)로 편집합니다.

3단계 · PCB

  1. 처음 들어오면 PCB 설계 시작 카드가 열립니다. 동박 층(2/4/6/8/10), 보드 크기(최소화 · 자동 · 직접), 배치 전략(균형 · 열 분산 · 노이즈 최소화 …), 이어서 자동 배선을 고릅니다.
  2. 도우미가 board layers → board minimize/reset → route를 차례로 실행합니다. 결과는 변경 요청 카드로 남고, 되돌릴 수 있습니다.
  3. PCB 편집(2D 보기 위)에서 부품을 끌어 옮기고(R 회전, F 뒤집기), 배선(X)·비아(V)를 그리며, 래츠네스트와 DRC 수를 확인합니다. 4층 이상이면 보기 탭 옆 층 선택(또는 [ ])으로 내층을 한 층씩 봅니다.
  4. 배선을 위해 회로를 함께 고칠 수 있습니다: pinswap으로 MCU 핀 배정을 바꾸면 보드 넷·회로도·HSIS가 함께 바뀝니다.

4단계 · 기구 CAD

  1. 왼쪽에서 설계 조건(발열 · IP 등급 · 진동 · 온도 · 재질 · 방열 패드)을 정합니다. 재질 6종(PC/ABS, PA66-GF, SPCC 판금, A6063 압출, ADC12·AZ91D 다이캐스팅)이 모두 계산되고 조건을 만족하는 최저 원가가 자동 선택됩니다.
  2. 도우미에 문장으로 지시합니다: "오른쪽 벽에 M16 글랜드 2개, 장착 탭 4개 M5, 커버 윗면 R3 둥근모따기". 구멍·사각 구멍·글랜드·벤트·탭·보스·리브·방열 핀·각인, 벽 두께·모서리 R/C·스탠드오프 등을 명령(hole · gland · tabs · fillet · edit …)으로도 넣습니다.
  3. 3D에서 요소를 클릭 선택(Shift/Ctrl 다중)하거나 형상 트리·부품(BOM 순) 띠에서 고른 뒤 선택 막대에 "지름 12로", "위로 3 mm", "삭제"처럼 적으면 그 요소에만 적용됩니다. 분해 슬라이더로 커버를 들어 올립니다.
  4. 오른쪽 아래에서 CAD 내보내기(SCAD·STL·보고서 zip), 도면·BOM(조립도·부품도 SVG/PNG·기구 BOM·SCAD), BOM Excel.

기존 프로젝트 열기

첫 화면의 기존 프로젝트 또는 머리의 파일 불러오기에서 파일을 끌어다 놓습니다. 여러 파일(Gerber 세트 + 드릴 + Pick-and-Place + BOM)도 한 번에 넣을 수 있고, 파일 역할은 자동 판별되며 직접 바꿀 수 있습니다.

열린 프로젝트에도 단계 표시줄이 보입니다. 1단계는 보드에서 추출한 HW 블록 다이어그램([보드에서 추출]로 편집 가능), 2단계 회로도, 3단계 PCB, 4단계 기구입니다. 이미 산출물이 있으므로 단계가 잠기지 않습니다.

설계 도우미(AI)

오른쪽 도킹 패널의 설계 도우미는 네 단계의 콘솔(시스템 CLI · 회로도 CLI · 배치/배선 CLI · Text-to-CAD)을 하나의 대화로 합친 것입니다. 입력은 지금 단계의 콘솔로 가고(머리의 선택 상자로 단계를 고정할 수 있음), 출력에는 어느 단계에서 나온 것인지 표시됩니다.

모드동작
결정론문장을 규칙으로 명령으로 바꿔 실행합니다. 예: "8층으로 바꾸고 크기 최소화" → board layers 8 → board minimize. 명령을 직접 적어도 됩니다.
AIClaude가 같은 명령을 도구로 하나씩 실행하고, 매 명령 뒤의 결과(경고·온도·원가·DRC)를 보고 고칩니다. 대화 방식(자동 · 질문 · 작업)과 모델 등급을 고를 수 있습니다.

변경 요청 카드

설계를 바꾼 실행마다 카드가 붙습니다: 시스템 · 회로(+추가 −삭제 값변경) · PCB · HSIS · 기구 · BOM 증감 영향, 변경 요약, 실행한 명령 목록.

  • 승인 · 리비전 기록: CR-n 이름으로 리비전을 남깁니다.
  • 겹쳐 보기: 직전 리비전과 현재를 PCB 겹쳐 보기로 엽니다.
  • 되돌리기: 그 실행이 더한 단계만큼 정확히 되돌립니다(그 뒤에 다른 변경이 있으면 Ctrl+Z 안내).

빠른 요청 칩은 단계마다 바뀌고, ` 키로 어디서든 입력창으로 갑니다. Enter 보내기, Shift+Enter 줄바꿈, ↑ 이전 입력.

보기 · 새 창

  • 3D(드래그 회전 · 우클릭/Shift 드래그 이동 · 휠 확대 · 클릭 선택, 등각/위/아래), TOP · BOTTOM(드래그 이동 · 더블클릭 맞춤), 층 선택(4층 이상, 내층), 회로도(시트 탭, 넷 강조).
  • 나란히: 회로도와 보드를 함께. 회로도에서 부품을 누르면 보드에서도 강조됩니다.
  • 새 창: 1×1 · 1×2 · 1×4 · 2×2 격자에 TOP · 내층 · BOTTOM · 3D · 회로도 · 시스템 다이어그램 · 부품 구성도 · 기구 3D · 기구 도면 · HSIS · 시뮬레이션을 배치합니다. 메인 창과 연동되고, 칸마다 SVG/PNG/Excel 버튼이 있습니다. 브라우저가 새 창을 막으면 화면 위에 떠 있는 창으로 열립니다.
  • 레이어 패널: 상단/하단/내층 동박, 실크, 솔더마스크(색 5종), 드릴·비아, 3D 부품/부품 외형, 반대면 비침, 3D 분해.
  • 정보 패널: 선택(패드·넷·부품), 부품 목록, 넷 목록, 데이터(불러온 파일·경고). 검색창에서 U1, 100nF, SDA처럼 찾습니다.

시뮬레이션

탭내용
전원 경로(IR drop)공급 핀에서 부하 핀까지 동박을 따라 흐르는 전류로 전압 강하와 트랙 발열. 부하 전류는 IC 핀에 나눠 넣습니다.
신호트랙 길이·임피던스·반사·크로스토크 추정, 차동 쌍 점검.
열부품 손실 → 보드 온도 분포(격자 해석), 부품별 Tj, 하우징과의 연계.
EMC모터 제어기 파라미터(PWM·슬루·루프 면적)로 방사 추정과 대책.
회로MNA 회로 해석과 MCU 펌웨어 코시뮬레이션(1 ms). 펌웨어 파라미터를 바꾸고 빌드 & 시뮬레이션을 누르면 3D에서 LED·모터가 움직입니다.

2D 보기 위에 결과를 겹쳐 볼 수 있고(범례 표시), 결과는 설계 보고서에 들어갑니다.

HSIS (HW/SW 인터페이스 사양)

  • 신호 표: 엑셀 HSIS(또는 보드에서 만든 초안)의 신호·분류·MCU 핀·포트·방향·넷. 상태(정상·경고·오류)와 필터.
  • MCU 핀 맵: 패키지 핀 배치 위에 신호를 그립니다. 핀을 누르면 보드·회로도에서 강조.
  • 추적성: 요구사항 ↔ HSIS ↔ 테스트 연결(SYS.4).
  • 검사 결과: 회로도 넷·보드·펌웨어·ARXML과 대조한 오류·경고 목록.
  • 핀 추천: MCU 핀 기능 DB로 역할(PWM·ADC·CAN·SPI …)에 맞는 핀을 추천(같은 주변장치 묶음, 헝가리안 매칭)하고 적용합니다.
  • MCAL 설정 · 테스트 케이스(SWE.6/SYS.4) 생성과 내려받기.

탭 머리의 Excel은 지금 탭의 표를, 내보내기 창의 "HSIS 전체"는 모든 표를 시트별로 저장합니다.

리비전 기록 · 비교

  • 설계를 바꾸면 2–4초 뒤 자동으로 리비전 r1, r2 …가 기록됩니다(원인 = 그 사이 실행한 명령, 단계, 변경 요약). 바뀐 게 없으면 기록하지 않습니다.
  • 지금 저장…으로 이름(A01, EVT1), 단계(Proto · EVT · DVT · PVT · MP), 메모를 붙입니다. 이름 붙인 리비전은 정리되지 않습니다(자동 리비전은 프로젝트당 최근 150개).
  • 비교: 목록에서 A·B를 고르거나(현재 포함) 원장의 열을 누릅니다(클릭 = B, Shift+클릭 = A). 탭: 요약 · 부품 · 배치 · 넷 · PCB 겹쳐 보기(같음 회색 / A에만 빨강 / B에만 초록, 층 선택) · 다이어그램·계획 · HSIS · 기구. Excel로 저장.
  • 복원: 지금 상태를 먼저 기록한 뒤 그 리비전으로 되돌립니다.
  • 기록은 이 브라우저(IndexedDB)에 프로젝트별로 남습니다. 기록 내보내기로 JSON 한 파일을 받아 설계 파일과 함께 Git에 커밋하고, 다른 PC에서 불러오기로 이어 봅니다.

자주 묻는 질문

3D가 안 보입니다. Three.js를 CDN에서 불러오지 못한 경우입니다. 인터넷 연결을 확인하거나 TOP·BOTTOM 보기를 쓰세요.

AI 모드가 "규칙으로 해석"으로 바뀝니다. Claude를 쓸 수 없는 환경(허용되지 않은 호스팅)에서는 결정론 규칙으로 대신 실행합니다. 기능은 같고 해석 폭이 좁습니다.

리비전이 다른 PC에서 안 보입니다. 기록은 브라우저 안에 저장됩니다. 기록 내보내기로 JSON을 받아 Git에 두고, 다른 곳에서 불러오기하세요.

단가가 실제와 다릅니다. 참고 단가는 데이터시트 페이지의 data-price(약 1k 수량, 추정) 또는 분류별 기본값입니다. datasheets/db/의 페이지를 채우면 정확해집니다.

하우징 벤트가 "부품 높이를 벗어남"으로 표시됩니다. 자동 벤트가 얇은 베이스에 다 들어가지 않는 경우입니다. edit F# --z <mm>로 커버 쪽으로 옮기세요.
