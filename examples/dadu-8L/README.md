## 만든 방법
앱에서 신규 설계 → Dadu 프로필(FET 첫 옵션, 전류 ~20 A, 패키지 축소 2단계, compact 전략, 보드 100 × 65 mm) → PCB 콘솔:
```
board layers 8
reset --strategy compact
route
```
