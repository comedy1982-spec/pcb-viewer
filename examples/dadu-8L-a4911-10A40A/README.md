## 만든 방법 (v1.80.0)
```
node scripts/pcbrun.cjs --cur "~10 A (소형 팬 · 펌프)" --param "gdrv3.driver=A4911,gdrv3.ipk=40,gdrv3.tpk=2" \
  --cmds "board layers 8; board size 90 60 --anchor center; reset --strategy compact --both --seed 23; route; fix --no-grow"
```
