응용 회로 · 주변 부품

  • 로컬 웨이크업 미사용 시 WAKE를 GND에 연결 (EMI)
  • INH: 하이사이드 출력, 180 µA에서 최소 VBAT-0.8 V; Sleep 시 고임피던스 → 외부 레귤레이터 차단
  • 디커플링·WAKE 저항/커패시터·종단 권장값은 읽은 발췌에 없음 — AH1309 (TJA1145 Application Hints) 확인. (데이터시트 ESD 시험 회로는 BAT 100 nF, WAKE 10 nF + 10 kΩ 사용 — 설계 권장값 아님)
  • SPI 최소 클럭 주기 250 ns(약 4 MHz), Sleep 중 1 µs

패키지 · 열

SO14 (SOT108-1) Rth(vj-a) 106 K/W, HVSON14(TK) 60 K/W. 과열 차단 167–187 °C, 해제/경고 127–147 °C.

설계 메모

  • 부품 DB 설명 'CAN 부분 네트워킹 · SPI · INH · WAKE · FD 수동'과 일치.
  • BAT 상승 시 INH 활성까지 tstartup 2.8 ms 일반 / 4.7 ms 최대. TXD 우성 타임아웃 2.7–3.3 ms.
  • Table 1의 IIO Sleep(58 µA 최대)과 Table 34(5/8 µA)가 불일치 — 원본 확인.
  • 후속품 TJA1145A (5 Mbit/s 대응, NXP 제품 페이지 검색 결과 기준 — 미확인 링크) 검토 가능.
