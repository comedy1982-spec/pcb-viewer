응용 회로 · 주변 부품

  • 출력 드라이버 세기 기본 50%, 12.5%까지 낮출 수 있음 (SRP 명령) — 긴 배선 링잉 시 조정.
  • VCC 디커플링 값은 데이터시트에서 확인 필요.

패키지 · 열

8핀 SOIC 208 mil. 외형 치수와 열 저항은 데이터시트 10.1절 확인 필요.

설계 메모

  • SOIC 208 mil은 일반 150 mil SOIC-8과 풋프린트가 다름 — KiCad SOIC-8_5.23x5.23mm_P1.27mm 후보, 치수는 데이터시트 10.1절로 확인.
  • Quad 모드 사용 시 WP#/HOLD#가 IO2/IO3로 쓰이므로 풀업 처리와 QE 비트 설정 확인.
  • 주문 코드 "JBLA3"에서 B=SOIC 208mil, A3=Auto Grade(-40~125 °C)만 문서로 확인. J, L 의미는 11절 확인 필요.
