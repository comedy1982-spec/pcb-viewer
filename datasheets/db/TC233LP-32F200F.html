핀 배치

PG-TQFP-100 · 100핀 MCU이므로 전체 핀 표 대신 핀 그룹만 정리합니다. TQFP-100 핀 번호는 데이터시트 2.3절(PG-TQFP-100-23)을 보세요.

핀이름기능
—VDD, VDDP3, VSS, VCAP0/VCAP1코어(1.3 V)·3.3 V 공급, EVR DCDC 관련 핀 (그룹 이름은 LFBGA-292 로직 심볼에서 확인)
—VDDM, VSSM, VAREF, VAGNDADC 공급·기준 전압
—XTAL1, XTAL2외부 크리스털/클럭 입력
—PORST, ESR0, ESR1파워온 리셋, 외부 서비스 요청(리셋/NMI)
—TMS/DAP1, TCK/DAP0, TRSTJTAG / DAP 디버그
—P00…P33 포트GPIO + 주변장치 다중화 (데이터시트 2장 포트 기능 표)

응용 회로 · 주변 부품

  • 공급 방식: 단일 공급 (VDDP3 3.3 V만 공급, EVR13이 1.3 V 생성) 또는 외부 공급 (VDD 1.3 V 외부 공급). 모든 VDDP3 핀은 PCB에서 서로 연결.
  • EVR13 LDO (온칩 패스 소자, IDD < 230 mA): VDD 출력 커패시터 COUT 1.4 / 2.2 / 3 µF (최소/일반/최대), ESR < 50 mΩ (0.5–10 MHz), 핀–커패시터 배선 저항 < 100 mΩ. 기동 시간 최대 1000 µs, 입력 램프 1–50 V/ms.
  • EVR13 DCDC (표 3-23, IDDDC=230 mA): 출력 COUTDC 6.5 / 10 / 13.5 µF, 입력 CIN 3.29 / 4.7 / 6.11 µF, 플라잉 커패시터 CFLY 0.7–1.3 µF, 각 ESR ≤ 50 mΩ (0.5–10 MHz). 값 범위는 DC 바이어스 포함 ±35 % 허용치이며 커패시터–레일 배선은 25 mΩ 이하, CFLY는 비아 없이 핀 가까이. 이 표에는 인덕터 항목이 없습니다.
  • DCDC 동작: 입력 VDDP3 2.97–3.63 V, fDCDC 0.4–2.0 MHz (설정), 출력 최대 250 mA, 리플 최대 26 mV, 효율 일반 72 % (3.3 V, 200 mA).
  • 전원 감시 (표 3-21): VDDP3 1차 저전압 2.86 / 2.92 / 2.97 V, VDD 1차 저전압 1.13 / 1.15 / 1.17 V, 2차 감시 VDDP3 3.23–3.37 V · VDD 1.27–1.33 V 범위.
  • 디커플링: VAREF는 외부 커패시터로 디커플링 필수. 데이터시트의 Pflash 전류 측정 조건은 ≥ 100 nF 디커플링. PLL 공급 잡음은 300 kHz 미만 100 mVpp, 300 kHz 이상 40 mVpp 이하 (전원핀 근접 블로킹 + 전원/접지 플레인).
  • 소비 전류 예산: 3.3 V 레일 IDDx3RAIL 34 mA (real) / 44 mA (Pflash 프로그래밍 포함), IDDM 최대 6 mA, DCDC 사용 시 전체 IDDTOTDC3 129 mA (VDDP3=3.3 V).

패키지 · 열

PG-TQFP-100-23 (12×12 mm 본체, 노출 패드). 노출 패드 치수 (표 3-44, L·LC·LP): 5.7 mm 및 4.9 mm (±50 µm) — 공칭 패드/납땜 가능 영역 구분은 원본 그림 확인.

열저항 (표 3-45, 노출 패드 납땜): 온칩 LDO 사용 시 RθJA 30.4 K/W · RθJCT 21.2 K/W · RθJCB 12.1 K/W; DCDC 사용 시 RθJA 20.4 K/W · RθJCT 11.9 K/W · RθJCB 2.9 K/W. TJ 최대 150 °C (SAK).

품질 (표 3-46): MSL 3 (J-STD-020C, 240 °C), ESD HBM 2000 V, CDM 500 V (모서리 핀 750 V), 동작 수명 tOP 24500 h.

설계 메모

  • 부록상 AB·AC 스텝 모두 생산 상태가 "on request"로 표기되어 있습니다. 신규 설계 시 공급 상태를 확인하세요.
  • 부록 표에서 AC 스텝의 CAN FD 플래그는 추출 텍스트만으로 열 매핑이 불분명했습니다. CAN FD가 필요하면 원본 표로 확인하세요.
  • 같은 계열 상위 핀수: TC234 (TQFP-144), TC237 (LFBGA-292).
  • 열 확인: TJ = TA + RθJA·PD. TA 125 °C, PD 460 mW이면 LDO 사용 시 약 139 °C, DCDC 사용 시 약 134 °C로 150 °C 이내. 노출 패드는 반드시 납땜 (열저항 조건).
  • 절대 최대 정격의 일반 입력 핀 상한은 VDDP3+0.6 V (최대 4.23 V)입니다. TC23x I/O는 5 V 내성이 없으므로 5 V 신호는 레벨 변환이 필요합니다 (아날로그·class S 입력만 7.0 V).
