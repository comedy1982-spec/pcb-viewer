응용 회로 · 주변 부품

  • 차지펌프 CP1–CP2: 470 nF 세라믹 (typ).
  • VBB 디커플링: 100 nF 세라믹을 공급·접지 핀 가까이.
  • VLR: 최소 1 µF, ESR ≤ 250 mΩ.
  • VREG 저장 커패시터·부트스트랩 커패시터 값은 데이터시트 Applications 절 참조 (이번에 읽은 범위에 수치 없음 — 데이터시트 확인 필요).
  • 전류 제한: 최대 임계 VMIT 200 / 100 / 50 / 25 mV 중 선택, ILIM = VILIM / RSENSE.
  • 데드타임 tDEAD = n × 50 ns (최소 100 ns), 기본 1.6 µs.
  • 부트스트랩 저전압: VREG의 60 ~ 71 % (하강).

패키지 · 열

JP: 32-리드 QFP 7×7 mm, 높이 최대 1.6 mm, 노출 패드. EV: 36-리드 QFN 6×6 mm, 높이 최대 1.0 mm, wettable flank, 노출 패드. RθJA: EV 27 °C/W (4층 JEDEC), JP 23 °C/W (4층 JEDEC), JP 44 °C/W (2층, 양면 3 in² 구리). TJ(max) 165 °C. RθJP는 읽은 범위에 없음.

설계 메모

  • MPN "A4964"는 기본 품번이며 주문 품번은 A4964KJPTR-T (LQFP-32) / A4964KEVTR-J (QFN-36) — 풋프린트 선택 시 패키지를 확정할 것. 생성기 핀 테이블은 JP(LQFP-32) 기준.
  • VBB가 3.5 V까지 떨어져도 SPI 통신이 유지되므로 크랭킹 중 진단 레지스터 판독 가능.
  • QFN(EV)은 GND 핀이 2개(16, 17) — 반드시 서로 연결.
  • 데이터시트 본문에서 게이트 수동 풀다운 값이 텍스트(950 kΩ)와 특성표(RGHPD/RGLPD 5 kΩ typ)로 다르게 표기됨 — 원문 확인 필요.
  • LIN 핀은 −40 ~ 50 V 내성, DIAG/IG는 50 V까지 — 차량 배터리 라인 직결 가능.
