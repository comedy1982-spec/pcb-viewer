응용 회로 · 주변 부품

  • EVRC 벅 DC-DC (외부 P/N MOSFET, VGATE1N/P): fDCDC 1.6 / 1.82 / 2.0 MHz (기동 500 kHz 개루프), 출력 최대 1.5 A (LPM 100 mA).
  • EVRC 외부 부품 (IDDDC 1.5 A 기준): 인덕터 2.31 / 3.3 / 4.29 µH @1.82 MHz (3.29 / 4.7 / 6.11 µH @0.8 MHz), DCR ≤ 0.2 Ω, 포화 전류 ≥ IDDDC + 400 mA. 출력 C 15.4 / 22 / 29.7 µF @1.82 MHz (20.8 / 32 / 43.2 µF @0.8 MHz), 입력 C 6.5 / 10 / 13.5 µF (500 mA면 4.42 / 6.8 / 9.18 µF), ESR ≤ 50 mΩ, 커패시터 공차 ±35 % (DC 바이어스 포함), 커패시터–레일 배선 ≤ 25 mΩ.
  • EVR33 사용 시 VDDP3에 외부 유도성 부하 금지.
  • 소비: PD 최대 1855 mW (max power pattern) / 1425 mW (real pattern) — TE/TX 공통. EVRC 동작 시 전체 전류 약 430 mA (VEXT 3.3 V) / 320 mA (5 V), TJ 150 °C.
  • EVR33 LDO (VEXT → VDDP3 3.3 V): 출력 커패시터 1.45 / 2.2 / 3 µF (최소/일반/최대), ESR ≤ 100 mΩ (0.5–10 MHz), 최대 60 mA (크랭킹 저전압 모드 40 mA). COUT 앞 핀 가까이에 100 nF 추가, 핀–커패시터 배선 저항 < 100 mΩ.
  • VEVRSB에 100 nF 이상 커패시터 필수 (대기 모드에서 2.6 V까지 강하 허용).
  • 공급 램프: VEXT/VEVRSB, VDDP3, VDD, VDDM 8.3·10−6 … 100 V/ms.
  • PLL 공급 잡음 (System/Peripheral PLL): 300 kHz 미만 100 mVpp, 300 kHz 이상 40 mVpp 이하. 공급 블로킹 커패시터는 공급 핀에 최대한 가깝게, 전원/접지 플레인 사용.
  • 클럭: XTAL1/XTAL2 메인 오실레이터 (주파수 범위·부하 커패시터는 읽은 부분에 없음 — 데이터시트 OSC_XTAL 절 확인).
  • 리셋·안전: PORST (파워온 리셋 입력, 전원 이상 시 강한 풀다운), ESR0 (기본 오픈드레인), ESR1 (리셋/NMI 트리거). TLF35584 같은 안전 PMIC와 조합할 때 연결은 각 데이터시트 확인.

패키지 · 열

PG-LFBGA-292. 열저항 (표 3-73, 최대): RθJA 22 K/W, RθJCT 5 K/W, RθJCB 4.5 K/W. TJ 최대 150 °C (SAK), TJ = TA + RθJA × PD.

설계 메모

  • TX는 TC37xEXT(확장 메모리·이더넷 2개) 칩입니다. TC37x 부록 v1.4에는 TC377TX가 없고 TC377TP(이더넷 1개)만 있습니다. 핀아웃도 TP와 TX가 다르므로 혼용하지 마세요.
  • 이전 초안의 보조 ADC 채널 수 64는 계열 최대치 — TC377TX 부록 값은 4/60채널.
  • 열 확인: RθJA 22 K/W로 TA 125 °C에서 PD 1.425 W (real)면 TJ ≈ 156 °C로 150 °C 초과. 고온 ECU에서는 방열(열 비아·케이스 접촉) 또는 TA/부하 저감 필요.
  • 절대 최대 정격의 VDD·VEXT 한계는 시간 제한형(2.8 h/72 h)입니다. 5 V 레일 과전압 보호를 5.6 V 이하로 설계하세요.
