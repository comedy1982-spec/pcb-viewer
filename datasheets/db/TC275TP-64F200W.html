응용 회로 · 주변 부품

  • 모든 VDD 핀, 모든 VEXT 핀, 모든 VDDP3 핀은 각각 PCB에서 서로 연결. EVR 사용 시 외부 유도성 부하 금지.
  • EVR33 (3.3 V, 표 3-36): 입력 4–5.5 V, 출력 커패시터 1 µF (ESR < 50 mΩ, 0.5–10 MHz), 기동 최대 1000 µs, 입력 램프 1–50 V/ms.
  • EVR13 LDO 모드 (외부 패스 소자, 표 3-37): VDD 출력 커패시터 3 / 4.7 / 6.3 µF.
  • EVR13 SMPS 외부 부품 (표 3-39, 1 A 기준): 출력 15.4 / 22 / 29.7 µF, 입력 6.5 / 10 / 13.5 µF, 커패시터 ESR ≤ 50 mΩ; 인덕터 2.31 / 3.3 / 4.29 µH (1.5 MHz) 또는 3.29 / 4.7 / 6.11 µH (1 MHz), 인덕터 ESR ≤ 0.2 Ω; 400 mA 설계는 출력 6.5 / 10 / 13.5 µF · 입력 4.42 / 6.8 / 9.18 µF. 외부 MOSFET은 로직 레벨, RON ≤ 150 mΩ @1 A.
  • EVR13 SMPS (표 3-40): 입력 2.97–5.5 V, fSW 0.4–2.0 MHz, 리플 ≤ 15 mV, 최대 출력 1 A, 효율 일반 85 % (3.3 V 입력, 300 mA, 1 MHz).
  • 디커플링: VEVRSB ≥ 100 nF, VDDFL3+VDDP3 공통 ≥ 100 nF (데이터시트 측정 조건).
  • 전원 감시 (표 3-38): 1차 저전압 VEXT 2.86 / 2.92 / 2.97 V, VDDP3 2.86 / 2.90 / 2.97 V, VDD 1.13 / 1.15 / 1.17 V.
  • 리셋: 전원 안정 후 PORST 최소 1 ms 유지, 파워온 부팅 최대 2.5 ms (1 V/ms 램프), PORST 해제 전 VEXT > 4 V (5 V 공칭) 또는 > 3 V (3.3 V 공칭). 기동 중 외부 레귤레이터 전류 증가는 100 µs당 50 mA로 제한.
