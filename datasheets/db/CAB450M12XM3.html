핀 배치

XM3 하우징, Inline 신호 핀 배치 — Wolfspeed PRD-07128 «XM Module Signal Pinout Clarification Guide»의 Table 1 (Inline pinout 모듈 목록)에 CAB450M12XM3이 들어 있습니다. 짝이 맞는 게이트 드라이버는 같은 문서 Table 2 (Inline): CGD1200HB2P-XM3, CGD12HBXMP, Si828x-AAWB-KIT, FRDMGD3160XM3EVM, EVAL-ADuM4177WHBBZ, UCC5880QEVM-057 등. Cross 배치 드라이버(CGD1700HB2P-XM3, Si828x-BAWB-KIT)와 짝지으면 단락 위험.

응용 회로 · 주변 부품

  • 게이트 구동 −4 / +15 V, QG 1330 nC → 구동 전력 ≈ QG × ΔVGS × fsw (예: 19 V, 20 kHz 에서 약 0.5 W/스위치). 절연 게이트 드라이버 (예: UCC5870-Q1) 의 2차측 손실 한도와 비교.
  • 드레인 켈빈 핀을 DESAT 감지에 사용, K1/K2 켈빈 소스로 게이트 루프 분리.
  • NTC: R25 = 4.7 kΩ ±1 %, P25 최대 50 mW, Steinhart–Hart 계수 A = 3.3540E−03, B = 3.0013E−04, C = 5.0852E−06, D = 2.1877E−07.

패키지 · 열

80 × 53 × 19 mm, 175 g, 구리 베이스플레이트. RthJC 0.11 °C/W (일반, 스위치당). 히트싱크 체결 M4 2.0–4.0 N·m.

설계 메모

  • 저인덕턴스(6.7 nH) 모듈 — DC 링크 커패시터를 적층 버스바로 직결해야 오버슈트를 억제할 수 있음.
  • VGS 음전압 한계가 −4 V(과도)로 좁음 — 바디 다이오드를 쓰는 경우 −8 V 사용 불가.
  • Wolfspeed는 XM 모듈과 게이트 드라이버의 핀 배치(Inline/Cross)를 잘못 짝지으면 단락으로 드라이버가 손상될 수 있다고 경고합니다.
  • 신호 핀은 Inline 배치 (PRD-07128 Table 1) — Inline 드라이버 보드와만 짝지을 것.
  • 보관 온도는 데이터시트(Rev. A) 텍스트에 없음 — TC −40 ~ 125 °C만 규정. SOA는 Fig. 18/19 그래프로만 제공, 단락 내량 수치 없음.
