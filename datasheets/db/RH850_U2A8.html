응용 회로 · 주변 부품

  • AWOVCL: 합계 0.140 / 0.2 / 0.286 µF (최소/일반/최대) — 모든 AWOVCL 핀에 고르게 나누거나 A22 한 핀에 집중.
  • GETH0VCL: 0.154 / 0.22 / 0.286 µF.
  • SVR 사용 시: SVRDRVCC 9 / 14 µF, SVRAVCC 0.7 / 1 / 1.3 µF, VDD 출력 커패시터 2 µF (LX 근처), LX 인덕터 2 µH (DCR 2 mΩ), 스위칭 368–500 kHz 또는 736–1000 kHz. SVRDRVCC 노이즈 ≤ 500 mV p-p.
  • RESET: 저레벨 폭 800 µs 이상, 400–2400 ns 펄스 제거. 전원 투입 리셋 유지 tRESH1 1.3 ms (SVR 사용 시 + tRUT), OSC 안정 5.5 ms, PLL 록 1 ms, VMON 상승 0.002–550 ms/V.
  • 모드 핀 입력 폭 600 ns 이상, FLMD0는 RESET 상승 후 전환 금지 (시리얼 프로그래밍 제외).

설계 메모

  • "RH850/U2A8"은 제품 그룹명이며 주문 품번이 아님 (데이터시트 Table 1.1 주문 정보 참조) — BOM에는 패키지·온도 등급을 포함한 주문 코드 사용.
  • U2A8은 BGA 패키지(292/373)만 제공 — 144/156/176핀 패키지는 U2A6 등 다른 그룹. 0.8 mm BGA 팬아웃에 맞는 기판 층수·비아 규칙 필요.
  • R7F702301BEBBA-C는 Table 1.1에서 MSPI·SVR 열이 "No" — SVR(스위칭 레귤레이터) 미지원 품목이라면 VDD 1.025–1.155 V를 외부에서 공급해야 함. 표 주석으로 의미 확인 후 전원 설계.
  • #BC6 접미사는 데이터시트에 없음 (Digi-Key 표기 "Quad-Core 400MHz 8MB 373-FBGA") — 포장/출하 코드로 추정.
