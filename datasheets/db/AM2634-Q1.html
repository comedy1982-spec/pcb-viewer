핵심 사양

CPU
Arm Cortex-R5F 최대 4코어, 최대 400 MHz (듀얼코어 클러스터 2개, 락스텝 가능)
메모리
코어당 I-캐시 16 KB / D-캐시 16 KB (ECC), 공유 TCM 256 KB, OCSRAM 2 MB (512 KB × 4뱅크, ECC)
통신
MCAN 4개 (CAN-FD), 2포트 이더넷 스위치 (RMII 10/100 · RGMII 10/100/1000, IEEE 1588/802.1AS)
아날로그
12비트 SAR ADC 5개 (각 최대 4 MSPS, 입력 6채널), CMPSS 20개, 12비트 버퍼 DAC 1개
제어 주변장치
EHRPWM 32, eCAP 10, eQEP 3, SDFM 2 (각 4채널)
보안
HSM (Auto SHE 1.1 / EVITA), 보안 부트, AES·SHA2·DRBG·PKA
기능 안전
ISO 26262 ASIL-D 목표 (읽은 판 기준 '인증 예정')
등급 · 온도
AEC-Q100, 확장 차량용 Tj -40 – 150 °C
패키지
ZCZ 324볼 nFBGA, 15.0 × 15.0 mm, 0.8 mm 피치

절대 최대 정격

데이터시트 확인 필요 (최신 SPRSP74 6.1절).

권장 동작 조건

데이터시트 확인 필요 (6.5절). 읽은 판에서 확인된 것: 디지털 I/O 레일 VDDSHV0 3.3 V, 아날로그 입력 레일 VDDA_CIO 3.3 V, ADC VREF 1.8 V, DAC_VREF 3.3 V.

핀 배치

ZCZ 324볼 BGA — 핀 표는 생략하고 그룹만 요약 (정확한 볼 번호는 데이터시트 Pin Attributes 표 참조).

  • 전원: 코어, 3.3 V I/O(VDDSHV0), 아날로그(VDDA_CIO), ADC/DAC 기준전압(ADCx_VREF, DAC_VREF0/1)
  • 클럭: XTAL_XI / XTAL_XO (주파수는 데이터시트 확인 필요)
  • 아날로그 입력: ADC0–4 각 6입력, CMPSS 입력 공유
  • 제어 I/O: EPWM, ECAP, EQEP, SDFM 핀 (멀티플렉싱)
  • 통신: MCAN0–3, RMII/RGMII + MDIO, UART/SPI/I2C 등

응용 회로 · 주변 부품

  • 디커플링, 전원 시퀀스(7.11절 참조), XTAL 부하 용량은 데이터시트 확인 필요.

패키지 · 열

ZCZ nFBGA 324볼, 15.0 × 15.0 mm, 0.8 mm 피치, 45 nm 공정. RθJA/RθJC는 데이터시트 확인 필요.
