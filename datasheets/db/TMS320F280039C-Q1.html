LQFP-100 (PZ) / 80 (PN) / 64 (PM) / 48 (PT) — 대형 MCU로 전체 핀 표 생략, 그룹 요약:

PZ(LQFP-100) 전원 핀 번호 (5.3.3 Power and Ground): VDD 4, 46, 71, 87 · VDDIO 3, 47, 70, 88 · VSS 5, 45, 72, 86 · VDDA 34 · VSSA 33 · VREGENZ 73 (내부 풀다운; VSS에 묶으면 내부 VREG 사용, VDDIO에 묶으면 외부 1.2 V 공급).

응용 회로 · 주변 부품

  • 내부 1.2 V LDO(VREG)는 VDDIO에서 전원을 받아 VDD 핀에 1.2 V를 공급 — VREGENZ를 VSS에 연결하면 활성. 내부 VREG 사용 시에도 VDD 핀 디커플링 커패시터가 안정성·과도 응답에 필요.
  • VDDIO·VDD는 디커플링 커패시터가 필요(6.12.1.3.1). 구체적 용량 값은 이번에 읽은 뷰어 페이지에 본문이 없어 미확보 — 6.12.1.3.1.1/6.12.1.3.1.2 및 TI 하드웨어 설계 가이드 확인.
  • BOR은 기본 활성. 전원 시퀀스는 6.12.1.4 참조.

설계 메모

  • MPN에 패키지 접미사가 없음 — 주문 시 PZ/PN/PM/PT 및 Q1 주문 코드 지정 필요. 기능안전(ASIL B) 인증은 PZ와 Q100 PM 패키지에만 적용.
  • CAN 2채널 중 CAN FD는 MCAN 1채널뿐 — CAN FD 2채널 필요 시 외부 컨트롤러(TCAN4551-Q1 등) 추가.
  • 'C' 변형 = CLB(구성 가능 로직 블록) 포함.
  • 내부 VREG 사용 시 3.3 V 단일 전원으로 동작 가능 — VREGENZ(PZ 73번 핀)를 VSS에 연결.
  • 도구 키 MPN F280039CPZRQ1 = PZ(LQFP-100) 패키지, key.spec pkg LQFP-100과 일치.
