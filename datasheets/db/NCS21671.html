핀 배치

Micro10 (DM): IN+, IN−, CIN+, CIN−, VS, GND, REF, EN, OUT, NC · SC70-6 (SQ): IN+, IN−, VS, GND, REF, OUT — 핀 번호는 데이터시트 Figure 2 확인 필요

핀이름기능
?IN+ / IN−션트 양단 입력 (셧다운 시 고임피던스)
?CIN+ / CIN−(Micro10) 선택적 입력 필터 커패시터 단자, 미사용 시 개방
?VS전원 (0.1 µF 바이패스)
?GND접지
?REF출력 기준: GND = 단방향, VS/2 등 = 양방향
?EN(Micro10) 개방 = 동작, 로 = 셧다운
?OUT출력 (셧다운 시 고임피던스)
?NC(Micro10) 무연결 — 외부 회로에 연결 금지

응용 회로 · 주변 부품

  • 전달식: VOUT = ILOAD × RSHUNT × GAIN + VREF.
  • VS 바이패스 0.1 µF를 핀 가까이.
  • 입력 필터(Micro10 CIN 핀): 이득별 내부 Rfilt 20 kΩ(G25) / 10 kΩ(G50) / 5 kΩ(G100) / 2.5 kΩ(G200), ±25 %. fc = 1 / (2π · 2Rfilt · Cfilt). 션트 L/R ≤ Rfilt · Cfilt가 되게 선정(1 mΩ 미만 션트에서 중요).
  • 외부 저항으로 이득을 바꾸지 말 것(내부 비율 정합 저항). 켈빈(4단자) 션트 권장.
