RH850/F1KM-S1

Renesas · MCU · 32-bit automotive MCU, single G3KH core 120 MHz (body/chassis)

핀 배치

48 / 64 / 80 / 100핀 QFP 계열 — 대형 MCU이므로 전체 핀표 대신 핀 그룹으로 요약. 패키지별 핀 기능(전원 VCC/EVCC/AVREF, CAN, RLIN3, CSIH, ADC 입력 그룹)은 하드웨어 매뉴얼의 핀 기능 장 확인 필요.

응용 회로 · 주변 부품

패키지 · 열

QFP48/64/80/100, 0.5 mm 피치. 열저항은 데이터시트 확인 필요. Tj 160 °C 고온 제품용 하드웨어 매뉴얼 부록(R01UH0956)이 별도로 있음 (미확인 링크).

설계 메모

  • "RH850/F1KM-S1"은 제품군 이름 — 메모리·핀 수·온도에 따라 여러 주문 품번 (예: 배포처 표기 R7F7016903AFP-C-AA1 LQFP64, R7F7016933AFP-C-AA1 LQFP48, R7F7016873AFP-C-AA1 LQFP80 — 배포처 검색 결과 제목 기준, 미확인).
  • 부품 DB 설명 "ASIL B": 제품 페이지에 MCU의 ASIL 등급 명시 없음 (응용 블록도에만 "supports ASIL B") — 안전 매뉴얼로 확인 필요.
  • 제품 페이지에 "CAN FD interface" 기재와 CAN-FD 채널 수 0이 함께 있어 모순 — 데이터시트로 확인.
