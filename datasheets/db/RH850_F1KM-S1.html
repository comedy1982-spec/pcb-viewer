핀 배치

80핀 LQFP (12 × 12 mm, 0.5 mm 피치) — 대형 MCU이므로 전체 핀표 대신 핀 그룹으로 요약 (데이터시트 3C.1.1.2 · 설계 가이드 표 1). 핀 번호는 데이터시트 2장 핀 배치 확인.

핀이름기능
—REGVCC / AWOVSS (PgR)내부 레귤레이터 전원 — X1, X2 포함 그룹
—AWOVCL / AWOVSSAlways-on 영역 내부 전압 — 안정화 커패시터 전용 (외부 전원으로 사용 금지)
—ISOVCL / ISOVSSIsolated 영역 내부 전압 — 안정화 커패시터 전용
—EVCC / EVSS (PgE)I/O 전원 — JP0, P0, P8, P9, P10, P11, RESET, FLMD0
—A0VREF / A0VSS (PgA0)ADC 기준·전원 — AP0 포트
—RESET, FLMD0리셋, 플래시 모드
—X1 / X2메인 발진기
—JP0_x디버그 (JTAG/LPD)
—포트CAN, RLIN3, CSIH, RIIC, ADC 입력 등 다중화

응용 회로 · 주변 부품

  • REGVCC: 4.7 µF 이상을 실장 패드 10 mm 이내에 추가 (설계 가이드 1.5절), 그림에는 0.1 µF도 병렬.
  • 100핀 S1 예 (표 43): 100 nF 권장 커패시터 C4, C6–C9, C11 · 안정화 커패시터 C5, C10은 70/100/130 nF (최소/일반/최대), ESR ≤ 40 mΩ 필수. 그림 16의 AWOVCL은 0.1 µF.
  • 메인 OSC (표 46): 8 / 16 / 20 / 24 MHz, 예시 C1 = C2 = 10 pF, Rd = 0 Ω — 실제 값은 진동자 제조사와 협의 (MOSCC.MOSCAMPSEL 게인 포함).
  • RESET: EVCC로 풀업 R1 1–10 kΩ, 선택 직렬 R2 100 Ω (EMC), C1 1–10 nF (서지 보호).
  • 전원 상승 기울기 0.02–500 V/ms, VPOC 구간(약 2.7–3.0 V) 통과 주의.
  • 데이터시트 3C.1.2.1: CAWOVCL 0.1 µF ±30 %, CISOVCL 0.1 µF ±30 % (핀당).
  • RESET 저레벨 폭 600 ns 이상 (전원 투입 제외), 100 ns 미만 펄스 무시. REGVCC 상승 후 RESET 해제까지 tDPOR 2 ms (0.02–0.5 V/ms) / 6.3 ms (0.5–500 V/ms).
  • LVI 검출 레벨 선택: LVI0 4.0 V, LVI1 3.7 V, LVI2 3.5 V (일반).

설계 메모

  • "RH850/F1KM-S1"은 제품군 이름 — 80핀 1 MB: R7F7016873AFP-C (Ta 105 °C) / R7F7016874AFP-C (Ta 125 °C), 768 KB: …7016883/4, 512 KB: …7016893/4 (데이터시트 Table 1C.2). 품번 R7F7016874AFP-C#AA1은 F1KM-S1 (F1KH 아님) 확인.
  • Digi-Key는 이 품번 RAM을 160 KB로 표기 — Renesas 품번 페이지(1 MB 품목)는 128 KB. 데이터시트로 확인 후 사용.
  • 부품 DB 설명 "ASIL B": 제품 페이지에 MCU의 ASIL 등급 명시 없음 (응용 블록도에만 "supports ASIL B") — 안전 매뉴얼로 확인 필요.
  • 제품 페이지에 "CAN FD interface" 기재와 CAN-FD 채널 수 0이 함께 있어 모순 — 데이터시트로 확인.
